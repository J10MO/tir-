# تير | tir

متجر أحذية إلكتروني: React (Vite) للواجهة، Node.js (Express) للخادم، وPostgreSQL لقاعدة البيانات.

## التشغيل لأول مرة

1. انسخ `server/.env.example` إلى `server/.env` وعدّل:
   - `DATABASE_URL`: كلمة مرور مستخدم `postgres`
   - `JWT_SECRET`: نص عشوائي طويل
   - `ADMIN_PHONE` و`ADMIN_PASSWORD`: حساب الإدارة الأول
2. ثبّت الحزم وجهّز قاعدة البيانات:
   ```
   npm run install:all
   npm run setup
   ```
   `setup` ينشئ قاعدة `tir` والجداول، ويضيف الأقسام والموديلات الخمسة بصورها وحساب الإدارة.
3. شغّل الخادم والواجهة في نافذتين:
   ```
   npm run dev:server
   npm run dev:client
   ```
   المتجر: http://localhost:5173 ، لوحة الإدارة: http://localhost:5173/admin

## للنشر

```
npm run build
npm start
```
الخادم يقدّم الواجهة المبنية من `client/dist` على نفس المنفذ (4000 افتراضياً).

## ما يحتويه

**المتجر:** الصفحة الرئيسية، تصفح حسب القسم والمقاس والسعر، صفحة المنتج بالألوان والمقاسات (مع طول القدم بالسنتيمتر)، السلة، إتمام الطلب بالدفع عند الاستلام وأجور توصيل حسب المحافظة، تتبّع الطلب برقمه ورقم الهاتف، حسابات الزبائن.

**الإدارة:** نظرة عامة (طلبات جديدة، مبيعات الشهر، المقاسات القريبة من النفاد)، إدارة الطلبات ومراحلها (إلغاء الطلب يعيد الكمية للمخزون)، إضافة وتعديل المنتجات بالألوان والصور والمقاسات والكميات.

صور المنتجات مفرّغة من الخلفية في `server/db/seed-images` (1200×900، والحذاء على خط أرضية واحد عند 92% من الارتفاع). الصور التي ترفعها من لوحة الإدارة لا تُفرَّغ تلقائياً، فارفعها بخلفية شفافة (PNG أو WEBP) لتظهر بنفس الشكل.

## هيكل المشروع

```
server/
  db/schema.sql      الجداول
  db/setup.js        إنشاء القاعدة وتطبيق الجداول
  db/seed.js         بيانات تجريبية وحساب الإدارة
  src/routes/        catalog, auth, orders, admin
client/
  src/pages/         صفحات المتجر
  src/pages/admin/   لوحة الإدارة
  src/styles/        الألوان والخطوط من شعار تير
```
